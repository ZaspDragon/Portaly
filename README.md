## What was fixed

- Cleaner buyer-facing role behavior
- Client Manager only sees selected client's workers, job sites, punches, and timesheets
- Worker role only sees the selected worker's timeclock and weekly hours
- QR links now preselect agency and job site using URL parameters
- Assignments now have a real create form
- Timesheets now include client IDs so client approval makes sense
- Payroll export respects the current role and selected tenant
- Agency/client/worker dropdowns stay synced when switching views
- Added empty states instead of awkward blank tables
- Improved professional UI polish
