# Portaly Role Sign-In + Location Lock

Upload these files to your GitHub Pages repo:

- index.html
- style.css
- app.js

## Added

- Separate sign-in card for each login type:
  - Worker
  - Client Manager
  - Agency Admin
  - Super Admin
- Sign Out button
- QRTimeclock-style worker punch screen
- Worker approval lockout
- Client/agency approval workflow
- 1-mile location lock for clock in/out/lunch punches
- Job sites now store latitude/longitude and punch radius
- Punch records save GPS verification and distance in miles

## Important

Browser location requires HTTPS. GitHub Pages uses HTTPS, so this will work on phones when users allow location permission.

After upload, click Reset Demo Data once.
