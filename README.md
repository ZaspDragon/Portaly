# Pallet Safety Checklist (Mobile Form)

Upload these files to a GitHub repository and enable GitHub Pages.

## Files
- index.html
- style.css
- app.js

## How to deploy
1. Create a new repo on GitHub.
2. Upload all files.
3. Go to Settings → Pages.
4. Set source to main branch / root.
5. Save.

Open the link on your phone and use it in the warehouse.

## Notes
- "Send Email" opens your mail app with the report pre-filled.
- Update the email address in app.js if needed.
