- Timeclock screen now follows your QRTimeclock style:
  - Worker Punch first
  - Name input
  - Four large punch buttons
  - Entered name, last action, last punch, status
  - Live punch feed next to it
- Color style updated to match the QRTimeclock blue/white worker-punch look

  - Worker Punch
  - Client Manager
  - Agency Admin
  - Super Admin

- Client/agency approval lockdown remains in place
